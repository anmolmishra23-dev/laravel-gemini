# Security Policy

## Supported versions

Security fixes are released for the latest minor version.

## Reporting a vulnerability

Please don't report security issues in public GitHub issues.

Report them privately through GitHub instead: open the repository's **Security** tab and click **Report a vulnerability**. You'll get a reply within a few days, and a fix will be released as soon as possible. You'll be credited in the release notes unless you'd rather not be.

If you've accidentally exposed a Gemini API key, revoke it right away in [Google AI Studio](https://aistudio.google.com/apikey).
